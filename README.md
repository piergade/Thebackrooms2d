# 无人抵达
这是一个俯视角的后室逃脱游戏。你需要不断探索周围地区，寻找出口，完成你回到前厅的愿望。祝你好运……

## 详情
- 这个游戏尚未完成，基本由ai制作，目前有96个关卡可用。
- 游戏应该尽量符合Wikidot中文社区的原始文本，当然，我也会对内容进行一些修改。
- 游戏有单人模式、AI模式和在线模式（局域网目前不可用，我也不知道为什么，但vibehub联机是可以的）。我认为性能优化不是很好，因为基本可以在低端设备上达到每秒30帧以上。

## 游玩
- 在浏览器里运行根目录下的`index.html`文件
- 要注意这样会导致你无法查看公告以及更新日志，如果你安装`python3`以上的版本，那么你可以运行根目录下的`start.bat`文件，并在浏览器里打开`localhost:8080`。
- 游戏测试网站`www.thebackrooms2d.de5.net`

### 操作方式
- WASD移动，手机端摇杆和按键操作

- 输入"DL.go(p=510256)"激活
- 注意不要滥用权限
- 按下Shift+F3截屏
