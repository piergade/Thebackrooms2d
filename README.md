# The Backrooms · 后室（2D 俯视探索）

> 一个在浏览器里运行的后室同人探索游戏。单机可玩，也支持房间制联机。
> 当前版本 **1.3.4**（版本戳 v=202）。

## 一、快速开始

1. 解压 `backrooms.zip`，用浏览器打开 `index.html` 即可单机游玩。
2. 建议用本地 HTTP 服务打开（录像存档、IndexedDB、联机更稳定）；联机时进入 `server/`，按其中的 README 启动 Node 服务端。
3. **本作是横屏游戏**，手机请横屏使用。
4. 可选资源：
   - 把自己的主菜单背景图命名为 `menu-bg.jpg` 放进 `img/`；不放也可以，界面会用纯色渐变兜底，包内不带默认图、不会覆盖你的文件。
   - 把 mp3 放进 `music/`，可消除底部「未检测到音乐文件」的提示（不影响操作）。

## 二、玩法

### 基本操作

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动 |
| Shift | 冲刺（消耗体力） |
| E | 交互：开门、拾取、查看铭牌、倚坐、购买、睡觉等 |
| F | 开关手电筒 |
| L | 开始 / 提前结束录像 |
| G | 手持层级密钥时，对着任意一扇门传送 |
| H | 从门上取回层级密钥 |
| Esc | 暂停 |

完整键位以游戏内「说明」面板为准。

### 核心循环

探索随机生成的层级 → 找到出口切到别的层级 → 管理生命、体力、理智与杏仁水等补给 → 避开或摆脱实体（笑魇、窃皮者、溺尸、沙灵……）→ 解锁层级档案、结局与彩蛋 → 用层级密钥打开枢纽里的门。

游戏内登记百余个层级，包含正式编号、子层（如 0.5、5.1、63.3）与隐秘层级；Level 0 内部还分拱门区、柱厅、熄灯区、深坑区等区域，各区地面完全一致，只是砌了不同的标志性建筑。熄灯区从边缘几格慢慢变黑、深处完全没有灯，通往 Level 0.5 的金属格栅楼梯就在它的深处。

### 物品与录像

- **胶卷**：普通胶卷 12 秒 / 24 帧每秒（开局自带 4 卷），高级胶卷 30 秒 / 30 帧每秒。按 L 消耗一卷，录完变成只能观看、导出、丢弃的录像带；丢在地上的录像带别的玩家可以捡起来看。
- **数码相机**：B.N.T.G 商店售 20 瓶杏仁水或等值 100 枚 B.N.T.G 货币，附送 3 颗电池；每颗电池维持 3 分钟，可录 720P / 30 帧每秒、花屏很轻的视频。按 L 起录，**录途中再按一次 L 直接结束**（胶卷照常扣掉一个，不退还）。电池 2 瓶杏仁水或 10 枚货币，也可在物资箱以 5% 概率刷出。
- 录像带的花屏、扫描线只存在于录像画面里，**玩家视角和 HUD 始终正常**；REC 常驻提示录制中，结束明确写「录像结束 · 已存进视频档案」。
- **层级密钥**：一把会发光的钥匙，每把对应一个层级。捡起后自动进快捷栏，对着**任意一扇已有的门**按 G 就能切到对应层级，按 H 取回；不需要、也不会新造一扇锁孔门。
- 没有专属图标的物品，在背包里显示的就是它在地图上的样子缩小版。

### B.N.T.G 商店与回收

Level 1「商人之家」和 Level 11「新时代广场」柜台都能买卖：层级密钥的品类、数量、摊位与价格随机，价格按档案分档；胶卷、数码相机、电池也在此出售，可用杏仁水或 B.N.T.G 货币支付。

**每个摊位都能回收**，但价格不同：

- 从 B.N.T.G 买来的东西，回收价固定为原价的 **3/4**；
- 自己捡来的东西，按该物品的 B.N.T.G 基准价上下 **1~2 瓶杏仁水 / 同价货币**浮动；
- **赫尔墨斯装置不可回收**。

### 联机

房间制，房主可先选**简单 / 普通 / 困难 / 极端**四档难度，设置同步给房内玩家。难度下方有**写实开关**并附作用提示：

- 开启后，Level 0 与 Level ! 生效「孤立效应」——每人一个独立副本，永远不会遇见队友；
- Level 37 生效非线性空间，进入时会被放到离所有队友最远的位置；
- 困难 / 极端模式下，不能通过「跟随队友」传送到队友所在的楼层。

### 档案与界面

档案手册分竖排大按钮，含层级、实体、物品、**结局档案（13 篇）**、**彩蛋档案（2 篇）**等分类；顶部「搜索」只搜当前这一页的内容，切页会带着关键词重新过滤。更新日志里当前版本占满整屏，下方「查看历史版本」可下滚，历史区顶部「查看最新更新」可回到开头。攻略界面可一键切换成中文维基 `https://brcn.backroomswiki.cn/`。

## 四、目录结构

```
backrooms/
├── index.html                 入口
├── css/style.css              全部样式
├── js/                        核心模块：main / map / entities / constants /
│                              config / ai / archive / audio / camera /
│                              cloud / lobby / net / opening

├── music/                     放 mp3（含占位 放这里.txt）

├── sql/                       建表脚本

```

## 五、几点说明

- 单机存档写在浏览器 IndexedDB，换浏览器或清缓存会丢失。
- 攻略里外链站点的 iframe 能否加载，取决于对方站点的访问与嵌套策略。
- 本作是对后室设定的同人演绎，具体以游戏内档案与实装为准。
