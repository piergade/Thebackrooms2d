# TheBackrooms2d - No one arrived/无人抵达

It is a backrooms escape game with a top-down perspective.You need to constantly explore the surrounding area, search for exits, and fulfill your desire to return to the front hall.Good luck……

这是一个俯视角的后室逃脱游戏。你需要不断探索周围地区，寻找出口，完成你回到前厅的愿望。祝你好运……

## Details/详情
- This game is not yet completed and is mostly made by AI. Currently, there are 30 levels available.
 这个游戏尚未完成，基本由ai制作，目前有30个关卡可用。
- The game should try to conform to the original text on the Wikidot Chinese community, but of course, I will also make some modifications to the content.
 游戏应该尽量符合Wikidot中文社区的原始文本，当然，我也会对内容进行一些修改。
- The game has single player mode, AI play mode, and online mode (currently only supports LAN). I don't think the performance optimization is very good, as it can basically achieve over 30 frames per second on low-end devices.
 游戏有单人模式、AI模式和在线模式（目前仅支持LAN）。我认为性能优化不是很好，因为基本可以在低端设备上达到每秒30帧以上。

## 游玩
Run the index.html file from the root directory in the browser
在浏览器里运行根目录下的index.html文件

- WASD Mobile,Mobile joystick and button operation
  WASD移动，手机端摇杆和按键操作

- Activate by entering 'DL. go (p=510256)'
  输入"DL.go(p=510256)"激活
- Be careful not to abuse your authority
